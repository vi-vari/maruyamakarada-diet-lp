# 円山カラダ整骨院 ダイエットLP

元ページ: https://maruyamakarada.net/menu/diet/lp/

元のLP（WordPress）を静的HTMLとして再現したものです。画像・CSS・JS・フォントはすべてこのリポジトリ内に保存しています。

## 構成

- `index.html` … LP本体
- `images/` … LPで使用している画像（元サイトおよびテンプレート配布元から取得）
- `css/` … スタイルシート（テーマ由来、Font Awesome）
- `js/` … jQuery とテーマのスクリプト
- `fonts/` … アイコンフォント（keni8-icons / Font Awesome）

## 表示確認

`index.html` をブラウザで開くだけで表示できます。

## 外部のまま残しているもの

- Google Tag Manager（GTM-52NM8HGM）… クライアントの計測タグ
- Google Fonts（M PLUS 1）
- Googleマップの埋め込み
- LINE / ホットペッパービューティーの予約リンク
